# Everyone Choice BD — Baby & Mom Care Storefront v2

## কী আছে
- মোবাইল/ডেস্কটপ responsive storefront
- ব্যবহারকারীর আপলোড করা ৩টি আসল পণ্যের ছবি
- পণ্য ক্যাটাগরি, সার্চ, কার্ট ও অর্ডার ফর্মের frontend demo
- Facebook Page link

## চালু করা
`index.html` ব্রাউজারে খুলুন। `assets` ফোল্ডারটি index.html-এর পাশেই রাখতে হবে।

## প্রকাশের আগে যা পূরণ করতে হবে
1. প্রতিটি পণ্যের সঠিক দাম ও বিস্তারিত বিবরণ
2. WhatsApp ব্যবসায়িক নম্বর (`index.html`-এ `WA` ভেরিয়েবল)
3. ফোন, ঠিকানা, ইমেইল ও ডেলিভারি চার্জ
4. বাস্তব অর্ডার সংরক্ষণের জন্য backend/database
5. নিরাপদ admin login এবং customer registration
6. অনুমোদিত payment gateway integration

**সতর্কতা:** এই সংস্করণটি frontend prototype; এটি এখনো production-ready e-commerce system নয়। এখানে কোনো real payment processing বা secure server-side order storage নেই।
